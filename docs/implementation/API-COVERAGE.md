# Frozen API coverage

104 qualified operations map to explicit runtime routes. The matrix is generated by scripts/coverage.mjs from the contract and Laravel route:list output. Controller modules identify the implementation and the corresponding storefront/admin feature.

Boundary tests exercise every owner/staff and account-only operation before validation. Scenario tests exercise real catalogue/media/content, guest/account access, shipping, stock, settlement, refunds and fulfillment; Playwright exercises critical visible journeys. A route and a permission assertion do not imply an independent positive integration test for every possible operation/payload. Real provider/hosting validation remains separate.
